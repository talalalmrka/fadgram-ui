# Typography

## Headings

<h1>H1 This is heading 1</h1>
<h2>H2 This is heading 2</h2>
<h3>H3 This is heading 3</h3>
<h4>H4 This is heading 4</h4>
<h5>H5 This is heading 5</h5>
<h6>H6 This is heading 6</h6>

## Paragraphs

### Simple paragraph

<p>This is simple paragraph.</p>

### Lead paragraph

<p class="lead">This is a lead paragraph. It stands out from regular paragraphs.</p>

## Blockquote

<blockquote>
  <p>
    This is a blockquote. It is used to quote a large section of text from
    another source.
  </p>
  <footer>— Someone famous</footer>
</blockquote>

## Lists

### Unordered list

<ul>
  <li>Unordered list item 1</li>
  <li>Unordered list item 2</li>
  <li>Unordered list item 3</li>
</ul>

### Ordered list

<ol>
  <li>Ordered list item 1</li>
  <li>Ordered list item 2</li>
  <li>Ordered list item 3</li>
</ol>
